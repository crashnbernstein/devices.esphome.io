## Notes

This is the new Waveshare ESP32 P4 with ESP32 C6 wifi chip. The LCD display is 800x480 and uses the mipi_dsi interface.

This board/display combo requires the following custom configuration, as ESPHome does not yet have a drop down for this board type.
